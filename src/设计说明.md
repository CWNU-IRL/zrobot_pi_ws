## 1. 软件总体设计

### 1.1 系统概述

本系统是一套基于 ROS 2 的人形机器人运动控制软件，运行于树莓派嵌入式平台之上，通过 CAN 总线驱动 23 个 RobStride 系列电机执行器，实现机器人的初始化归零（FixStand）以及基于深度强化学习策略网络的步行运动（Locomotion）两种控制模式。

系统主要特点：

| 特性 | 说明 |
|------|------|
| 控制周期 | 100 Hz |
| 执行器数量 | 23 个 RobStride 电机 |
| 通信总线 | 4 路 CAN（can10 ~ can13） |
| 传感器 | IMU（高速串口 2 000 000 bps） |
| 推理框架 | ONNX Runtime（2 线程推理） |
| 观测维度 | 47 维 |
| 动作维度 | 12 维 |

### 1.2 设计目标

1. **安全性**：通过线性插值平滑运动，避免急动；服务调用超时保护。  
2. **实时性**：主控循环 100 Hz；推理独立线程异步执行，不阻塞控制输出。  
3. **可扩展性**：抽象 FSM 基类，新增状态机只需继承并实现 `run()` 方法。  
4. **可维护性**：模块化设计，各功能层职责单一，通过 ROS 2 服务/话题解耦。

## 3. 模块名称与功能

| 包名 | 可执行文件 | 主要功能 |
|------|-----------|---------|
| `zrobot_deploy` | `main`（`zrobot_fsm_controller` 节点） | 上层控制逻辑，FSM 管理，键盘交互 |

### 3.2 各模块详细说明

#### 3.2.1 `zrobot_deploy` — 控制逻辑包

| 子模块 | 文件 | 功能描述 |
|--------|------|---------|
| 程序入口 | `main.cpp` | 初始化 ROS 2 节点、键盘交互（F/S/Q）、主循环 @100 Hz |
| FSM 基类 | `FSM.h / FSM.cpp` | 定义控制接口，封装服务调用，管理电机反馈缓存 |
| 归零状态机 | `FixStand.h / FixStand.cpp` | 三阶段 FSM，将 23 个电机平滑插值到机械零位 |
| 步行状态机 | `Locomotion.h / Locomotion.cpp` | 订阅 IMU 与速度指令，通过 ONNX 网络推理生成 12 个关节位置指令 |

| 子模块 | 文件 | 功能描述 |
|--------|------|---------|

| 子模块 | 文件 | 功能描述 |
|--------|------|---------|
| IMU 驱动节点 | `imu_driver_node.hpp / imu_driver_node.cpp` | 串口读取原始数据，转换为物理量，发布两个 ROS 2 话题 |

#### 3.2.4 `rs_interface` — 公共接口定义包

| 服务定义 | 功能 |
|---------|------|
| `RobStrideMsgs.srv` | 23 个电机的位置控制请求/反馈 |
| `GetPositions.srv` | 读取当前 23 个电机绝对位置 |
| `SetZeros.srv` | 设置电机机械零位 |

## 4. 接口设计

### 4.1 ROS 2 服务接口

#### 4.1.1 `/rob_stride_control`（`RobStrideMsgs.srv`）

```
# ---- 请求 ----
float32[23] positions   # 23 个电机的目标角度（弧度）

# ---- 响应 ----
float32[23] feedback_positions      # 实测角度（弧度）
float32[23] feedback_velocities     # 实测角速度（rad/s）
float32[23] feedback_torques        # 实测力矩（N·m）
float32[23] feedback_temperatures   # 电机温度（°C）
bool        success                 # 执行是否成功
string      message                 # 错误或状态信息
```

- **服务端**：`motor_controller_node`  
- **客户端**：FSM 基类（`sendMotorPositions()`）  
- **调用频率**：100 Hz  
- **超时设置**：100 ms  

#### 4.1.2 `/get_positions`（`GetPositions.srv`）

```
# ---- 请求 ----
# （空）

# ---- 响应 ----
float32[23] feedback_positions   # 当前 23 个电机绝对角度（弧度）
bool        success
string      message
```

- **服务端**：`motor_controller_node`  
- **客户端**：FSM 基类（`getCurrentPositions()`）  
- **典型调用场景**：`FixStand` 初始化阶段读取当前位置  
- **超时设置**：5 s（单电机响应可能较慢）  

#### 4.1.3 `/set_zeros`（`SetZeros.srv`）

```
# ---- 请求 ----
# （空）

# ---- 响应 ----
bool   success
string message
```

- **用途**：将当前位置设为 23 个电机的机械零位  

### 4.2 ROS 2 话题接口

#### 4.2.1 `/imu/data`（`sensor_msgs/msg/Imu`）

| 字段 | 含义 |
|------|------|
| `header` | 时间戳与坐标系 |
| `orientation` | 四元数（由欧拉角转换） |
| `angular_velocity` | 陀螺仪数据（rad/s） |
| `linear_acceleration` | 加速度计数据（m/s²） |

- **发布者**：`imu_data_node`  
- **订阅者**：`Locomotion`（`imuCallback()`）  

#### 4.2.2 `/imu/ImuDataWithRPY`（`imu_msg/msg/ImuData`）

```
std_msgs/Header  header
sensor_msgs/Imu  imu       # 标准 IMU 数据
float64          roll      # 横滚角（弧度）
float64          pitch     # 俯仰角（弧度）
float64          yaw       # 偏航角（弧度）
```

- 比标准 IMU 额外携带欧拉角，便于直接使用姿态信息  

#### 4.2.3 `/cmd_vel`（`geometry_msgs/msg/Twist`）

| 字段 | 含义 |
|------|------|
| `linear.x` | 前进速度指令（m/s） |
| `linear.y` | 横移速度指令（m/s） |
| `angular.z` | 转向角速度指令（rad/s） |

- **发布者**：外部遥控节点或上位机  
- **订阅者**：`Locomotion`（`cmdCallback()`）  

### 4.3 参数接口

#### 4.3.1 `motor_controller_node` 参数

| 参数名 | 类型 | 默认值 | 说明 |

| `imu_topic` | `string` | `imu/data` | IMU 话题名 |
| `cmd_topic` | `string` | `cmd_vel` | 速度指令话题名 |

### 5.2 FixStand 归零状态机流程

```
FixStand::initialize()
  │
  ▼
FSM::initialize() — 等待 /rob_stride_control 服务就绪
  │
  ▼
getCurrentPositions() — 调用 /get_positions 读取初始位置
  │ 失败则 initial_positions_ = 0
  ▼
记录 start_time_、last_time_
internal_state_ = MOVING
  │
  ▼
┌─────────────────── run() @100 Hz ───────────────────────┐
│                                                          │
│  计算 dt = 当前时间 - last_time_                         │
│  elapsed_time_ += dt                                     │
│                                                          │
│  switch(internal_state_):                                │
│    ┌── MOVING ──────────────────────────────────────┐   │
│    │  t = min(elapsed_time_ / 3.0, 1.0)             │   │
│    │  for i in 0..22:                               │   │
│    │    pos[i] = lerp(initial[i], 0.0, t)           │   │
│    │  sendMotorPositions(pos)                        │   │
│    │  if t >= 1.0:                                   │   │
│    │    internal_state_ = STANDING                   │   │
│    │  else: 每秒打印进度                              │   │
│    └────────────────────────────────────────────────┘   │
│                                                          │
│    ┌── STANDING ────────────────────────────────────┐   │
│    │  pos = target_positions_(全0)                  │   │
│    │  sendMotorPositions(pos) — 持续维持位置         │   │
│    │  每 5 秒打印一次状态                             │   │
│    └────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────┘
```

### 5.3 Locomotion 步行状态机流程

```
Locomotion::initialize()
  │
  ├── FSM::initialize() — 等待服务
  ├── initializeParameters() — 从 ROS 参数服务器加载参数
  ├── create_subscription(imu_sub_)  ← /imu/data
  ├── create_subscription(cmd_sub_)  ← /cmd_vel
  ├── loadPolicy(model_path)         ← 加载 ONNX 模型
  └── 启动推理线程 inferenceLoop()
  │
  ▼
┌────────────────── inferenceLoop() @100 Hz（独立线程）────────────────┐
│  loop:                                                                │
│    start = Clock::now()                                               │
│    ++counter_                                                         │
│    collectObservations()                                              │
│      ├── 加锁读取 angular_velocity, gravity_vector, command          │
│      ├── getMotorFeedback() 读取位置/速度                             │
│      ├── 计算步态相位 sin/cos(2π×counter×dt/period)                  │
│      └── 归一化: obs_scaled = (obs - mean) ⊙ scales                  │
│    runInference()                                                     │
│      ├── 构造输入张量 (1×47)                                          │
│      ├── ort_session_->Run(...)                                       │
│      ├── 读取输出张量 (1×12) → act_prev_                             │
│      └── 加锁写入: act_scaled = act_prev ⊙ act_scales + act_mean     │
│    sleep_until(start + dt_)                                           │
└───────────────────────────────────────────────────────────────────────┘
  │
  ▼（主线程调用 run()）
Locomotion::run()
  ├── 加锁读取 act_temp_ = act_scaled_
  ├── positions[0..11] = act_temp_[0..11]
  └── sendMotorPositions(positions)
```

### 5.4 电机控制服务调用流程

```
FSM::sendMotorPositions(positions[23])
  │
  ▼
创建 RobStrideMsgs::Request
request->positions = positions
  │
  ▼
control_client_->async_send_request(request)
  │
  ▼
spin_until_future_complete(node_, future, 100ms)
  │
  ├── TIMEOUT ──► 记录错误，返回 false
  │
  └── SUCCESS
        │
```

## 8. 算法设计

### 8.1 线性插值算法（FixStand）

FixStand 在 MOVING 阶段使用线性插值（Lerp）平滑过渡电机位置，避免急动冲击：

$$
\theta_i(t) = \theta_{i,0} + t \cdot (\theta_{i,\text{target}} - \theta_{i,0}), \quad t = \min\!\left(\frac{\Delta T}{T_\text{interp}}, 1\right)
$$

其中：
- $\theta_{i,0}$：初始位置（启动时通过服务读取）
- $\theta_{i,\text{target}} = 0$（机械零位）
- $\Delta T$：自插值开始的已过时间
- $T_\text{interp} = 3.0 \text{ s}$：插值总时长
- $t \in [0, 1]$：无量纲插值参数（到达 1 后钳位）

代码实现（`FixStand.cpp`）：

```cpp
float FixStand::lerp(float start, float end, float t) {
    return start + t * (end - start);
}
```

### 8.2 强化学习推理算法（Locomotion）

#### 8.2.1 观测向量组成（47 维）

| 索引范围 | 内容 | 归一化方式 |
|---------|------|---------|
| [0, 3) | 机体角速度 ω（rad/s） | × `ang_vel_scale` |
| [3, 6) | 机体坐标系重力向量 **g**（g 方向投影） | × 1.0 |
| [6, 9) | 速度指令 (vx, vy, ωz) | × 1.0 |
| [9, 21) | 关节位置偏差 θ − θ_default（rad） | × `dof_pos_scale` |
| [21, 33) | 关节速度 θ̇（rad/s） | × `dof_vel_scale` |
| [33, 45) | 上一步动作 a_{t-1} | × 1.0 |
| [45, 47) | 步态相位（sin, cos） | × 1.0 |

归一化公式：

$$
\hat{o} = (o - \mu_o) \odot s_o
$$

其中 $\mu_o$ 为 `obs_mean_`，$s_o$ 为 `obs_scales_`，$\odot$ 为逐元素乘法。

#### 8.2.2 步态相位计算

步态相位利用计数器 `counter_` 和控制周期 `dt_` 计算：

$$
\phi = \frac{(counter \cdot dt_) \bmod T_\text{period}}{T_\text{period}}, \quad T_\text{period} = 0.8 \text{ s}
$$

$$
o_{45} = \sin(2\pi\phi), \quad o_{46} = \cos(2\pi\phi)
$$

#### 8.2.3 重力向量计算

从 IMU 四元数旋转矩阵 $R$ 将世界坐标系重力向量 $(0, 0, -1)$ 转换到机体坐标系：

$$
\mathbf{g}_\text{body} = R^\top \cdot \begin{pmatrix}0 \\ 0 \\ -1\end{pmatrix}
$$

#### 8.2.4 动作反归一化

ONNX 网络输出 $a_\text{raw}$（12 维），反归一化得到最终电机目标角度：

$$
\theta_\text{cmd} = a_\text{raw} \odot s_a + \mu_a
$$

其中 $s_a$ = `act_scales_`（默认 `action_scale` 倍的全 1 向量），$\mu_a$ = `act_mean_`（默认角度偏置）。

### 8.3 PD 位置控制算法（电机端）

每个 RobStride 执行器内置 PD 控制器，接收上层指令计算输出力矩：

$$
\tau_\text{out} = K_p \cdot (\theta_\text{ref} - \theta) + K_d \cdot (\dot{\theta}_\text{ref} - \dot{\theta}) + \tau_\text{ff}
$$

$$
\tau_\text{out} = \text{clamp}(\tau_\text{out}, -\tau_\max, +\tau_\max)
$$

- $K_p$：比例增益（由 `motor_kps` 配置，默认 1.0）
- $K_d$：微分增益（由 `motor_kds` 配置，默认 0.5）
- $\tau_\text{ff} = 0$（位置模式下前馈为零）

### 8.4 CAN 帧数据量化算法

物理量与整数之间的转换使用线性量化，以充分利用有限位宽：

**编码（float → uint）：**

$$
x_\text{uint} = \text{round}\!\left(\frac{x - x_\min}{x_\max - x_\min} \cdot (2^{bits} - 1)\right)
$$

**解码（uint → float）：**

$$
x = x_\min + \frac{x_\text{uint}}{2^{bits} - 1} \cdot (x_\max - x_\min)
$$

各物理量的编码范围：

| 物理量 | 范围 | 位宽 |
|--------|------|------|
| 位置 θ | [−4π, +4π] rad | 16 bit |
| 速度 ω | [−ω_max, +ω_max] rad/s | 16 bit |
| 力矩 τ | [−τ_max, +τ_max] N·m | 16 bit |
| 比例增益 Kp | [0, Kp_max] | 16 bit |
| 微分增益 Kd | [0, Kd_max] | 16 bit |

### 8.5 IMU 数据处理算法

原始 16 位整型数据转换为物理量：

| 物理量 | 转换公式 |
|--------|---------|
| 加速度（m/s²） | raw × 9.8 / 32768 |
| 角速度（rad/s） | raw × (2000°/s) / 32768 × π/180 |
| 欧拉角（rad） | raw × 180° / 32768 × π/180 |

四元数由欧拉角（ZYX 顺序）按照 ROS 标准转换方法（`tf2::Quaternion`）生成。

### 9.5 错误处理策略

| 错误场景 | 处理方式 |
|---------|---------|
| 服务不可用（启动超时） | `initialize()` 中每秒重试，直到服务就绪或 ROS 退出 |
| 运动控制服务超时（100 ms） | 打印 ERROR 日志，本次控制周期跳过，下周期继续 |
| 位置读取服务超时（5 s） | 打印 WARN 日志，initial_positions_ 设为全零继续 |
| 电机反馈位置数量不符 | 跳过反馈更新，使用上次缓存值 |
| 推理线程未启动 | run() 打印 WARN 并直接返回 |
| FixStand 未初始化调用 run() | 打印 ERROR 并返回 |
| CAN 帧发送失败 | send_motion_command() 返回错误，上层记录日志 |
